# Sarakie

> Rooted in Botswana. Great Financing For your future.

Sarakie is a financial services platform providing accessible, transparent, and fast personal, business, and payday loan options tailored for everyday needs in Botswana.

## Features

- **Landing Page**: Overview of loan products and services
- **Loan Calculator**: Instant calculations for loan repayments
- **Loan Application**: Streamlined application workflow
- **Customer Portal & Dashboard**: View and manage active loans, status, and repayment history
- **Admin Management**: Admin profile, loan approval sheets, and customer records

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

```bash
npm install
```

### Local Development

```bash
npm run start
```

### Production Build

```bash
npm run build
```

### Preview Build

```bash
npm run preview
```

## Deployment

Configured for seamless deployment on [Vercel](https://vercel.com/) with SPA routing rewrites (`vercel.json`).
